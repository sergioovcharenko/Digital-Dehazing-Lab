# Digital Dehazing — офлайн запуск

## Що працює локально
- відкриття фото;
- відкриття локального відео;
- LIVE-камера;
- WebL / Adaptive MAX;
- Classic DCP;
- AUTO з адаптацією DAY / EVENING / NIGHT;
- MANUAL LOW / MEDIUM / HIGH;
- 50/50, два кадри, два малі кадри, тільки оброблений;
- стоп-кадр і збереження PNG;
- zoom;
- індикатори FPS, ms, вхідної та вихідної роздільності.

AI-режими EDN-GTM та AIDTransformer вважаються експериментальними, доки в пакет не додані локальні моделі ONNX та локальний ONNX Runtime.

## Windows / macOS / Linux

Не відкривайте index.html напряму через file:// — браузери обмежують камеру і Service Worker.

1. Розпакуйте ZIP.
2. Запустіть START_WINDOWS.bat на Windows або START_MAC_LINUX.command на macOS/Linux.
3. Відкрийте адресу http://127.0.0.1:8080
4. Дозвольте доступ до камери, якщо використовуєте LIVE.

Потрібен Python 3. Сервер працює тільки на вашому пристрої та не відправляє фото/відео назовні.

## iPhone / iPad

1. Один раз відкрийте веб-версію через HTTPS.
2. Safari → Поділитися → На екран «Додому».
3. Після того як ресурси закешовано, базовий інтерфейс і локальна обробка можуть працювати без інтернету.
4. Доступність LIVE-камери в PWA залежить від політик iOS/Safari.

## Android

1. Один раз відкрийте веб-версію через HTTPS у Chrome.
2. Встановіть як вебзастосунок, якщо Chrome запропонує.
3. Для максимально надійної офлайн-роботи та Camera2 рекомендований окремий Digital Dehazing APK.

## Камера

- AUTO — рекомендований режим.
- 1080p — мінімальна затримка та стабільний live.
- MAX — браузер просить максимально доступну роздільність; фактичну якість визначає камера та браузер.
- FPS: AUTO / 30 / 60.
- Якщо пристрій надає hardware zoom через браузер, використовується він; інакше застосовується локальний digital zoom.
